## 为什么要读财报

上市公司必须定期公开财务报告。股价每天都在变，而财报告诉你这家公司实际做得怎么样。

财报的核心是三张表：

| 表 | 回答的问题 | 时间 |
|---|---|---|
| 利润表 | 这段时间赚了多少钱？ | 一段时间（季度或年度） |
| 资产负债表 | 公司有什么、欠什么？ | 某一天的快照 |
| 现金流量表 | 现金实际流进流出多少？ | 一段时间 |

下面用一家**假设的公司**“枫叶咖啡”来看。单位都是百万美元。

## 利润表：赚了多少

| 项目 | 金额 | 说明 |
|---|---|---|
| 营业收入 | 1000 | 卖咖啡收到的钱 |
| − 营业成本 | 600 | 咖啡豆、门店人工等 |
| **= 毛利** | **400** | 毛利率 40% |
| − 销售和管理费用 | 200 | 租金、广告、总部开支 |
| − 研发费用 | 50 | |
| **= 营业利润** | **150** | 营业利润率 15% |
| − 利息费用 | 10 | 借款的利息 |
| − 所得税 | 30 | |
| **= 净利润** | **110** | 净利率 11% |
| 总股数 | 100 | |
| **每股收益（EPS）** | **$1.10** | 110 ÷ 100 |

从上往下读，就是一块钱收入被一层层扣掉成本，最后剩下多少。

几个常用的比率：

- **毛利率** = 毛利 ÷ 收入。反映产品本身赚不赚钱。
- **营业利润率** = 营业利润 ÷ 收入。反映主营业务扣掉日常开支后赚不赚钱。
- **净利率** = 净利润 ÷ 收入。
- **每股收益（EPS）** = 净利润 ÷ 总股数。第 12 课的市盈率就用它来算。

单看一年的数字意义不大。和公司**过去几年**比，和**同行**比，才能看出好坏。

## 资产负债表：有什么、欠什么

资产负债表是某一天的快照，永远满足一个等式：

**资产 = 负债 + 股东权益**

| 资产 | 金额 | 负债和权益 | 金额 |
|---|---|---|---|
| 现金 | 150 | 应付账款 | 100 |
| 应收账款 | 120 | 短期借款 | 50 |
| 存货 | 80 | 长期借款 | 250 |
| 厂房和设备 | 650 | **负债合计** | **400** |
| | | **股东权益** | **600** |
| **资产合计** | **1000** | **合计** | **1000** |

- **应收账款**：客户已经买了、但还没付的钱。
- **应付账款**：公司已经买了、但还没付给供应商的钱。
- **股东权益**：资产减去负债，属于股东的部分，也叫净资产。

两个常看的比率：

- **负债权益比** = 负债 ÷ 股东权益 = 400 ÷ 600 ≈ 0.67。数字越高，借的钱越多，经营不顺时风险越大。不同行业差别很大，银行和公用事业公司负债天然较高。
- **净资产收益率（ROE）** = 净利润 ÷ 股东权益 = 110 ÷ 600 ≈ 18%。表示股东投入的每一块钱一年赚了多少。

## 现金流量表：钱到底进没进口袋

利润表上的利润，不等于真正收到的现金。比如客户赊账，收入已经记上了，钱还没到。现金流量表把现金的实际流动分成三部分：

| 项目 | 金额 | 说明 |
|---|---|---|
| 净利润 | 110 | 从利润表来 |
| + 折旧 | 60 | 记为费用，但当年没有付出现金 |
| − 应收账款增加 | 40 | 收入记了，钱没收到 |
| − 存货增加 | 10 | 钱花在了还没卖出去的货上 |
| **经营活动现金流** | **120** | |
| 购买设备、开新店（资本支出） | −100 | |
| **投资活动现金流** | **−100** | |
| 偿还借款 | −20 | |
| 发放分红 | −30 | |
| **筹资活动现金流** | **−50** | |
| **现金净变化** | **−30** | |

一个常用指标是**自由现金流**：

**自由现金流 = 经营活动现金流 − 资本支出 = 120 − 100 = 20**

它表示公司维持和扩张业务之后，还能自由支配的现金。枫叶咖啡的净利润是 110，自由现金流只有 20，主要是因为它在开新店。这本身不是坏事，但你需要知道利润和现金之间差了多少、为什么。

::: warning 需要多看一眼的信号
- 净利润连续多年远高于经营活动现金流。
- 应收账款增长明显快于收入增长。
- 借款逐年增加，而利润没有跟着增加。
- 每年都有“一次性”费用。
:::

## 财报去哪找

美国上市公司的报告都提交给 SEC，在 SEC 的 **EDGAR** 数据库里免费查。公司官网的“投资者关系（Investor Relations）”页面通常也会放。

| 报告 | 内容 | 截止时间（大型公司） |
|---|---|---|
| **10-K** | 年报，包含经审计的完整财务报表和业务、风险说明 | 财年结束后 60 天内 |
| **10-Q** | 季报，前三个季度各一份，财务报表未经审计 | 季度结束后 40 天内 |
| **8-K** | 重大事件，如高管变动、收购、财报发布 | 事件发生后几个工作日内 |

规模较小的公司截止时间更晚：10-K 为 75 或 90 天，10-Q 为 40 或 45 天。

10-K 很长，新手可以先读三部分：**业务介绍（Business）**、**风险因素（Risk Factors）**、**管理层讨论与分析（MD&A）**，再看三张表。

::: info 注意“调整后”的数字
公司发布财报时，常常强调“调整后利润”（non-GAAP），通常会去掉股权激励、重组费用等项目。这些数字不受统一会计准则约束，各公司算法不同。把它和按会计准则（GAAP）计算的净利润对照看。
:::

## 小结

- **利润表**看赚了多少，**资产负债表**看有什么、欠什么，**现金流量表**看现金实际进出。
- 资产 = 负债 + 股东权益。
- 利润不等于现金；**自由现金流**是经营现金流减去资本支出。
- 财报在 SEC 的 EDGAR 上免费查：10-K 是年报，10-Q 是季报，8-K 是重大事件。
- 数字要和公司过去比、和同行比。
