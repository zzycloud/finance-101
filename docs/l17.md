## 期权价格 = 内在价值 + 时间价值

**内在价值（intrinsic value）**：假如期权现在立刻到期，它值多少。

- 看涨期权：股价 − 行权价（小于 0 时记为 0）
- 看跌期权：行权价 − 股价（小于 0 时记为 0）

**时间价值（time value）**：期权价格中超出内在价值的部分。离到期还有时间，股价还可能变动，这种可能性本身值钱。

例子：股价 $52，行权价 $50 的看涨期权报价 $3.50。

- 内在价值 = 52 − 50 = $2
- 时间价值 = 3.50 − 2 = $1.50

价外期权没有内在价值，价格全部是时间价值。到期那一刻，时间价值归零，只剩内在价值。

## 影响期权价格的因素

| 因素变化 | 看涨期权 | 看跌期权 |
|---|---|---|
| 股价上涨 | 涨 | 跌 |
| 行权价更高 | 更便宜 | 更贵 |
| 离到期时间更长 | 通常更贵 | 通常更贵 |
| 波动率升高 | 涨 | 涨 |
| 利率升高 | 略涨 | 略跌 |

其中最难直接观察的是**波动率**。

## 隐含波动率

波动越大，股价在到期前大涨或大跌的可能越大，期权就越值钱。

**隐含波动率（implied volatility，IV）** 是从期权的市场价格反推出来的波动率，代表市场对未来波动的预期。券商的期权报价页面一般会显示每个期权的 IV。

- IV 高：期权贵。常见于财报、重大消息之前，或者市场恐慌时。
- IV 低：期权便宜。

### 财报后的 IV 下降

财报前，市场不知道结果，IV 常常很高。财报公布后，不确定性消失，IV 往往迅速下降。

下面用 Black-Scholes 模型估算一个例子：股价 $100，买入行权价 $100、14 天后到期的看涨期权。

| | 财报前 | 财报后第二天 |
|---|---|---|
| 股价 | $100 | $102（+2%） |
| 隐含波动率 | 60% | 30% |
| 期权价格 | 约 $4.69 | 约 $3.42 |

股价方向猜对了，期权却跌了约 27%。买期权不仅要猜对方向，还要涨得够多，才能抵消 IV 下降和时间损耗。

## 希腊字母

券商会显示几个用希腊字母命名的指标，衡量期权价格对不同因素的敏感度。

以一份看涨期权为例：股价 $100，行权价 $100，30 天后到期，隐含波动率 30%，价格约 $3.43（按 Black-Scholes 模型估算）。

| 指标 | 含义 | 本例 | 怎么读 |
|---|---|---|---|
| Delta | 股价涨 $1，期权价格变多少 | 约 0.52 | 股价涨 $1，期权约涨 $0.52，一份合约约 $52 |
| Gamma | 股价涨 $1，Delta 变多少 | 约 0.05 | 股价涨 $1，Delta 从 0.52 升到约 0.57 |
| Theta | 过一天，期权价格变多少 | 约 −0.06 | 其他不变，每天约少 $0.06，一份合约约 $6 |
| Vega | IV 升 1 个百分点，期权价格变多少 | 约 0.11 | IV 从 30% 升到 31%，期权约涨 $0.11 |

几个规律：

- **Delta**：看涨期权在 0 到 1 之间，看跌期权在 −1 到 0 之间。平价期权约 ±0.5，深度价内接近 ±1，深度价外接近 0。
- **Gamma**：平价、临近到期时最大，这时 Delta 变化很快，期权价格大起大落。
- **Theta**：对买方通常是负数，对卖方是正数。卖方赚的就是时间价值的流逝。
- **Vega**：到期时间越长，Vega 越大，对 IV 变化越敏感。

## 时间损耗

时间价值不是均匀减少的，越接近到期，减少得越快。

还是上面那份期权，假设股价一直是 $100、IV 一直是 30%，按 Black-Scholes 模型估算：

| 距离到期 | 期权价格 |
|---|---|
| 90 天 | 约 $5.94 |
| 60 天 | 约 $4.85 |
| 30 天 | 约 $3.43 |
| 14 天 | 约 $2.34 |
| 7 天 | 约 $1.66 |
| 1 天 | 约 $0.63 |

从 90 天到 60 天，价格少了约 $1.09；最后 30 天，剩下的 $3.43 全部消失。

所以买入临近到期的平价或价外期权，看起来便宜，但时间价值流失得最快。

::: warning 模型只是估算
Black-Scholes 等模型假设波动率不变、股价连续变动，和真实市场有差距。上表的数字只用来说明规律，实际价格由市场买卖决定。
:::

## 小结

- 期权价格 = **内在价值** + **时间价值**；到期时时间价值归零。
- **隐含波动率**越高，期权越贵；财报后 IV 下降，可能让期权在股价方向正确时仍然亏钱。
- **Delta** 看方向，**Gamma** 看 Delta 变化，**Theta** 看时间损耗，**Vega** 看波动率。
- 越接近到期，时间价值消失得越快。
